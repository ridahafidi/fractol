# Fract-ol

A graphical fractal visualization project developed as part of the 42 curriculum.

The objective is to explore mathematical fractals by generating and rendering complex mathematical sets, allowing users to interactively navigate and customize their visual representations.

## 🛠️ Technologies

- **Language:** C
- **Graphics:** MiniLibX
- **Mathematics:** Complex numbers and iterative functions
- **Rendering:** Pixel manipulation and color mapping
- **Build System:** Makefile
- **Environment:** Linux / Unix

## 🎨 Implementation

Implemented a graphical application capable of rendering fractals through mathematical iteration and pixel-based visualization.

### Core Features

- Generated fractal visualizations using mathematical iteration.
- Implemented fractal rendering through complex number calculations.
- Mapped screen coordinates to the complex plane.
- Applied color gradients based on iteration counts.
- Managed keyboard and mouse events.
- Implemented interactive zooming and navigation.
- Optimized rendering and pixel manipulation.

### Fractals

Common fractal sets explored in this project include:

- **Mandelbrot Set:** A fractal generated by iterating a complex quadratic function.
- **Julia Set:** A family of fractals generated using different complex constants.

## 🧠 Concepts Explored

- Complex numbers and mathematical iteration.
- Fractal geometry.
- Coordinate transformations.
- Computer graphics and pixel rendering.
- Color interpolation and gradients.
- Event-driven programming.
- Memory management and graphics resources.
- Rendering optimization.

## 🚀 Compilation

Clone the repository:

```bash
git clone <repository-url>
cd fract-ol
```

Compile:

```bash
make
```

Run the program:

```bash
./fractol mandelbrot
```

For a Julia set:

```bash
./fractol julia
```

*Additional arguments depend on the implemented fractal configurations.*

## 🎮 Controls

| Input | Action |

| Mouse wheel | Zoom in / out |
